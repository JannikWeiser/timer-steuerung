# Timer-Steuerung

Steuerseite für zwei Timer von [timer.itsblue.de](https://timer.itsblue.de) nebeneinander.

- Pro Timer mit Name und Passwort anmelden (die Anmeldung bleibt nur im eigenen Browser gespeichert)
- Live-Vorschau und Status per WebSocket
- Neustart, Pause/Fortsetzen, Segment überspringen – einzeln oder für beide Timer gleichzeitig
- Display-Link zum Kopieren für beliebig viele Anzeigen

Reine statische Seite (`index.html`), kein Server nötig – läuft über GitHub Pages oder lokal per Doppelklick.
